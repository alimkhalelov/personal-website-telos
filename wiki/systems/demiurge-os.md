# Demiurge.OS & Living Agent Harness

**Demiurge.OS** is the architectural operating system powering `https://alim.dest.page/`. It combines full-stack web technologies with stateful agentic memory harnesses, enabling seamless co-creation between human product vision and autonomous AI execution.

---

## 1. The 7-Layer Agent Architecture

```
Layer 7: UI & Presentation   ─── Next.js 15, Tailwind v4, Avant-Garde Minimalist Theme
Layer 6: Living Knowledge    ─── AI-Wiki 3-Column Shell, GraphRAG, Deterministic AST
Layer 5: AI Engine & Models  ─── Multi-model routing (Gemini 3.1 Pro, 3.5 Flash, 3.0 Flash)
Layer 4: Agent Execution     ─── Loop Engineering, ReAct feedback, Critic QA
Layer 3: Living Memory       ─── Persistent User Intent Matrix, Facts JSONL, Git Ledger
Layer 2: Git Storage CMS     ─── Markdown/MDX repository backing, Outstatic CMS
Layer 1: Edge Infrastructure ─── Vercel Serverless Functions, Edge Networks, MCP APIs
```

---

## 2. Living Agent Memory & Anti-Recency Engine

To overcome LLM context decay during multi-day sprints:

- **Immutable User Intent**: Core constraints and vision are preserved in `raw/user-intents.md` and `.agents/wiki/user_intent.md`.
- **Zero-State Harness Hook**: Every subagent automatically syncs with the central project manifest before executing commands.
- **Context Mutation Gate**: Any conflicting directives trigger an explicit verification gate before mutating recorded constraints.
