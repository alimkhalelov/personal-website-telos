# AI-Wiki Git Ledger & Release Changelog

## [v1.0.0] - 2026-08-15
- **Initial Native Wiki Release**: Complete integration of the 3-column Avant-Garde AI-Wiki knowledge portal into `https://alim.dest.page/`.
- **Obsidian AST Graph**: Deployed full-spectrum deterministic knowledge graph (`/wiki/graph`) mapping relationships between methodologies.
- **Notion Database Properties**: 2-column reactive properties component with versioning, CategoryRAG grounding badge, and collapsible toggle.
- **2-Tab Search Modal**: Global `⌘K` modal providing instant client-side fuzzy search across all concepts and Grounded AI query answering.
- **Serverless MCP API**: Deployed `/api/mcp` endpoint supporting `capabilities`, `get_page`, `search_wiki`, and `get_graph`.
- **GEO Discovery Suite**: Deployed `/llms.txt` and integrated Next.js sitemap.
