# CategoryRAG Grounding Engine

**CategoryRAG** is the grounding protocol used across the wiki and search modals. It enforces a strict invariant: **if information is not present in the verified project graph, the AI must explicitly refuse to hallucinate**.

## Verification Protocol

1. **AST Extraction**: Every wiki document is parsed into an abstract syntax tree capturing headings, frontmatter, and explicit wikilinks `[[slug|Label]]`.
2. **Deterministic Cross-Referencing**: When answering user queries, the retrieval engine checks exact entity boundaries before generating responses.
3. **Provenance Attribution**: Answers generated by Ask AI include verifiable links back to the source node (e.g. `/wiki/concepts/loop-engineering`).

## Serverless MCP Interface

CategoryRAG exposes its query interface via the `/api/mcp` endpoint, enabling external tools, IDE extensions, and subagents to consume verified knowledge without hallucinations.
