# Zero-Click Onboarding Systems

Every click in an onboarding funnel represents a 10-25% drop-off risk. **Zero-Click Onboarding** is the product design philosophy of reducing friction to zero by inferring intent from ambient signals.

## Fundamental Tenets

- **Progressive Disclosure**: Only ask for input when mathematically required.
- **Ambient Inference**: Pre-populate configuration from repository metadata, user locale, and device context.
- **Immediate Value Delivery**: Show working demonstrations before prompting for account creation, following the [[concepts/fan-filter-scale|Fan-Filter-Scale]] activation paradigm.
