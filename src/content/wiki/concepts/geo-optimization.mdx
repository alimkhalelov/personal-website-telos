# Generative Engine Optimization (GEO)

As search moves from 10 blue links to generative synthesis engines (Google AI Overviews, Perplexity, ChatGPT Search), optimization strategies must evolve from meta keywords to **information provenance and entity authority**.

## Core GEO Strategies

1. **Entity Disambiguation**: Clear Schema.org JSON-LD graph definition linking [[entities/alimzhan-khalelov|Alimzhan Khalelov]] to published works, frameworks, and code repositories.
2. **Standardized Discovery Endpoints**:
   - `llms.txt`: Curated markdown index of all core concepts for fast ingestion.
   - `llms-full.txt`: Complete un-truncated documentation corpus.
   - `/api/mcp`: Standardized [[systems/category-rag|Model Context Protocol endpoint]] allowing direct tool querying.
3. **Passage-Level Citability**: Structuring prose with explicit claims, definitions, and reproducible benchmarks so AI summarizers can cite direct quotes without paraphrase distortion.
